# Лабораторные работы по ОПГИКС

Приложения на Python и PyQt5 по курсу «Основы проектирования графического
интерфейса компьютерных систем». В папках находятся исходный код и отчёты Word.

| Папка | Работа |
| --- | --- |
| `l1` | Переключение надписи и изображения по нажатию кнопки |
| `l2discuss` | Конвертер валют с использованием сигналов и слотов |
| `l3sql` | Просмотр SQLite-базы и результатов SQL-запросов в пяти вкладках |
| `l4` | Редактор Painter на QML с сохранением Canvas по таймеру |

## Запуск

Установите Python 3 и PyQt5:

```shell
python -m pip install -r requirements.txt
```

Перейдите в папку нужной работы и запустите:

```shell
python main.py
```

Для первой работы файл `image.jpg` должен находиться рядом с `main.py`.
В третьей работе выберите `Menu → Set connection` и откройте `demo.db`.
В четвёртой работе рисунок сохраняется в `autosave.png` каждые 5 секунд.
